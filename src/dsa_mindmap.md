## Recognition Cheat Sheet

```text
Sorted + pair movement
      → Two Pointers

Subarray + negatives
      → Prefix Sum + HashMap

Longest + sequence + unordered
      → HashSet

Missing numbers in range 1..n
      → Cyclic Sort

Maximum contiguous
      → Kadane

Need O(1) space rearrangement
      → In-place pattern

One element appears > n/2
      → Moore Voting
```
